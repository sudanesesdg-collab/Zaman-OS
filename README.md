# لغة زمان (Zaman Language)

> أول لغة برمجة عربية لبناء أنظمة التشغيل

## الرؤية

بناء نظام تشغيل كامل بلغة برمجة عربية من الصفر.

## الميزات

- متغيرات وثوابت
- دوال
- شروط
- حلقات
- مصفوفات
- مكتبة قياسية
- مفسر
- مترجم إلى C

## البدء

git clone https://github.com/sudanesesdg-collab/Zaman-OS.git
cd Zaman-OS
cargo run
